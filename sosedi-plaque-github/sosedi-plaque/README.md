# Дом «Соседи» · серия табличек с планировками

Версия 1.0 · 16 ноября 2026

Этот комплект фиксирует оформление таблички с квартирой 43,8 м². При выпуске следующей таблички открыть `template.svg`, сохранить фиксированный фон и заменить планировку и данные квартиры. Синий слайд о дистанционной покупке относится к отдельной серии материалов САР.

## Файлы

| Файл | Назначение |
|---|---|
| `template.svg` | Редактируемый макет. Текст справа и план размещены отдельными группами. |
| `assets/base.png` | Зафиксированный фон с двумя логотипами, ботаническим декором, наклонной плашкой и двумя золотыми линиями. Фон под планом и текстом восстановлен по окружающему тону. |
| `assets/reference.png` | Вырезанная лицевая панель из образца. По ней сверять геометрию, цвета и декор. |
| `assets/plan-example.png` | План из образца с прозрачностью по внешнему контуру. Пример размещения и визуального исполнения. |

## Типографика

Рабочая замена по форме букв — **Montserrat** с кириллицей. В шаблоне настроен резервный **Open Sans**, с ним проверен экспорт. Семейство исходного шрифта и исходный кегль не установлены по растровому образцу. При появлении оригинального файла уточнить семейство и проверить ширину строк. ## Как выпустить следующую табличку

1. Скопировать папку или SVG рядом с `assets/`. Сохранить группу `fixed-art` в той же позиции и масштабе. В ней находятся оригинальные видимые листья, прожилки, оба логотипа, форма плашки и линии.
2. В группе `plan` заменить пример прозрачным SVG или PNG новой планировки. Общий масштаб выбирать по занимаемому полю. Контур стен, проёмы, считывание лоджии и открывание дверей переносить из актуальной схемы квартиры. Ширину стен сохранять по геометрии плана. У стен образца внешняя визуальная толщина около 37 px, внутренние перегородки 11–12 px. Это пропорции образца, без привязки к строительным размерам. Проверить, что новая планировка не перекрывает логотипы и видимые листья. Часть листьев, скрытая стеной на исходнике, отсутствует в доступном растре.
3. В группе `copy` заменить количество комнат, площадь, абзац и преимущества. Сверить площади и состав помещений с карточкой квартиры. Текст умещать в 6 строк абзаца и 3 строки списка за счёт редакторской правки. Для более длинного заголовка сократить формулировку и проверить зазор до плашки. При замене заголовка и площади проверить параметры `textLength` и фактическую ширину новой надписи. Для новых табличек допустима десятичная запятая по карточке квартиры. В примере SVG сохранены видимые написания из образца.
4. Экспортировать пробный PNG и сверить с `assets/reference.png` в масштабе 1:1. Проверить границы, межколоночный отступ, читаемость, знаки, плашку, линии и поля. В Inkscape экспортировать SVG кнопкой «Экспорт». В командной строке можно использовать `inkscape template.svg --export-filename=preview.png`. Для печати проверить фон в требуемом физическом размере. SVG содержит растровый фон 1378 × 855 px и текст, который остаётся векторным при экспорте в PDF.
5. Для хранения в GitHub распаковать архив и закоммитить папку целиком, например в `brand/sosedi/apartment-plaques/`. Сохранять относительные пути к `assets/`.

## Что зафиксировано по образцу

В исходнике показана готовая табличка под интерьерным светом. Видимые элементы декора, наклонная плашка и логотипы сохранены в растровом слое. Участки под старым планом и надписями восстановлены, поэтому фон на этих участках приближённый. Доступный корпоративный файл `SAR_logo_CMYK.pdf` показывает другие цветовые версии логотипа. На табличке использовано зелёно-золотое исполнение из предоставленного визуала. Для подготовки крупноформатного тиража оригиналы знаков и листьев в векторе позволят воспроизвести их на нужном разрешении.
